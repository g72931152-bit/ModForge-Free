# ModForge — полноценный стартовый проект

ModForge — веб-сервис для проверки и безопасного исправления BeamNG ZIP-модов.

## В этой версии уже работает

- drag-and-drop ZIP;
- загрузка файла в backend с progress bar;
- backend на FastAPI;
- лимит входного ZIP 2 ГБ;
- защита от path traversal;
- защита от слишком большого распакованного архива;
- статический анализ JSON/JBeam/PC/materials файлов;
- поиск ссылок на DDS/PNG/JPG/DAE/CDAE/JBeam/PC/JSON;
- поиск отсутствующих ресурсов;
- безопасные исправления однозначно сопоставимых путей/регистра;
- новый `_FIXED.zip`;
- JSON-отчёт;
- веб-страница отчёта;
- готовая структура для будущего BeamNG headless renderer;
- место под рекламу, поддержку и Premium.

## Запуск

1. Запусти backend по инструкции `backend/README.md`.
2. В `frontend/config.js` укажи URL backend.
3. Отдай `frontend` через любой static host или локально.

## Важное ограничение

Это уже не демонстрация интерфейса: ZIP действительно загружается, анализируется и пересобирается. Но невозможно честно назвать статическим анализатором полноценный автоматический «ремонт любой машины». Для визуального стекла, UV, освещения и некоторых материалов нужен runtime-тест в настоящем BeamNG/BeamNG.tech окружении. Поэтому такой runner предусмотрен архитектурой отдельно.

## Монетизация

Frontend содержит места под рекламный блок, поддержку проекта и Premium. Платёжные сервисы подключаются самостоятельно; их условия и возрастные ограничения нужно соблюдать.
