# ModForge v2

Это новая структура ModForge для GitHub + Render. В отличие от прошлой one-file версии, здесь приложение разделено на понятные файлы, чтобы брендовые изображения и настройки можно было менять без редактирования Python-кода.

## Файлы

- `Dockerfile` — сборка для Render.
- `main.py` — сайт, API, анализатор и автоисправления.
- `site_config.json` — поддержка автора, рекламный блок и название сайта.
- `assets/logo.png` — логотип сайта и favicon.
- `assets/banner.png` — баннер. Рекомендуемый размер 1280×640.

## Как поменять логотип и баннер

Просто замени:

- `assets/logo.png`
- `assets/banner.png`

Имена оставь прежними. После `git commit` + `push` Render заново соберёт сайт.

## Поддержка автора

В `site_config.json`:

```json
"support_url": "https://...",
"support_label": "Поддержать проект"
```

При пустом `support_url` блок поддержки скрыт и на публичной странице нет текста про неподключённую ссылку.

## Реклама

Пока реклама отключена:

```json
"ad_enabled": false
```

Когда будет готова рекламная интеграция, её можно включить через настройки, не меняя основной интерфейс.

## Что изменено

- Нормальный filename для исправленного ZIP: `<имя>_FIXED.zip`.
- Нормальный filename для JSON-отчёта: `<имя>_report.json`.
- Исправлена отдача ZIP через `Content-Disposition`.
- Минималистичный чёрно-белый интерфейс с оранжевым акцентом.
- Адаптация под телефон, планшет, компьютер и большие экраны.
- Убран технический текст, написанный от лица разработчика.
- Ограничение визуальной проверки описано нейтрально: сервис проверяет содержимое архива, а не заявляет, что запускал BeamNG.
- Поиск ресурса теперь умеет находить уникальный файл по имени, если исходная ссылка сломана.
- Исправление путей с неправильным регистром.
- Автоматическая нормализация параметров материалов стекла, когда материал однозначно распознан как стекло.
- Сохраняются только действительно нерешённые предупреждения.
- Поддержка автора и рекламный блок скрыты, пока они не настроены.

## Важно про автоматическую замену ассетов

ModForge не копирует случайные игровые файлы BeamNG в пользовательский мод. Для стекла используется безопасная настройка материала по документированной схеме BeamNG; чужие текстуры/модели не подставляются автоматически без проверки прав на их распространение.

## Render

- Language: Docker
- Branch: `main`
- Root Directory: пусто
- Dockerfile Path: `./Dockerfile`
- Environment Variables: не обязательны

Большие архивы зависят от доступных ресурсов платформы. Лимит приложения остаётся 2 ГБ.
