# ModForge FINAL

Для твоего текущего GitHub-репозитория достаточно загрузить `Dockerfile` из этого архива. Всё приложение встроено в него: frontend, FastAPI backend и анализатор. Поэтому Render не ищет отдельные папки `backend/` и `frontend/`.

## Render
- Language: Docker
- Branch: main
- Root Directory: пусто
- Dockerfile Path: `./Dockerfile`
- Compute: Free
- Environment Variables: не требуются для первого запуска

После Commit changes Render автоматически запустит новый deploy.

## Возможности
- выбор ZIP или папки в браузере;
- drag-and-drop ZIP;
- лимит 2 ГБ на уровне приложения;
- поле пожеланий;
- прогресс загрузки и анализа;
- безопасная распаковка ZIP;
- защита от `../`, абсолютных путей и symlink entries;
- проверки JSON / PC / JBeam скобок;
- поиск ссылок на DDS/PNG/JPG/DAE и другие ресурсы;
- автоматическое исправление только однозначной ошибки регистра пути;
- отчёт `ИСПРАВЛЕНО / ПРЕДУПРЕЖДЕНИЕ / OK`;
- генерация `<имя>_FIXED.zip`;
- скачивание готового ZIP и JSON-отчёта;
- ограничение больших загрузок;
- мобильный и ПК-интерфейс.

## Важное ограничение

Реальный рендер самой BeamNG (геометрия стекла, отражения, освещение, `NO TEXTURE` на готовом кадре) бесплатный Render не выполняет. Интерфейс прямо показывает это как отдельную проверку, а сервис не делает вид, что видел машину в игре. Для такого этапа позже нужен отдельный runner с BeamNG/BeamNG.tech и GPU.

## Бесплатный Render

Render Free Web Services засыпают после 15 минут без входящего трафика, а следующий запрос может разбудить сервис примерно за минуту. Файловая система Free-инстанса эфемерная, поэтому готовые архивы являются временными и не являются постоянным хранилищем.
