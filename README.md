# ModForge v1 (0.27) — BeamNG.drive mod repair

## Что нового в 0.27

### Исправлено
- **Кнопки во время подготовки** — «Пауза» и «Файлы» скрыты на этапе загрузки файла; в этот момент они бессмысленны. Отображаются только при реальной обработке.
- **Фаза подготовки**: корректная смена IDLE → PREPARING → PROCESSING → DONE.
- Кнопка «Остановить» на этапе загрузки теперь прерывает XHR.

### Добавлено
- **Змейка** 🐍 — мини-игра на Canvas открывается автоматически во время загрузки файла. Управление: WASD / стрелки / свайп. Рекорд сохраняется между сессиями.
- **Анимированный фон** — Canvas-частицы с dot-grid и линиями связей.
- **Сохранение сессии (1 час)** — если браузер закрылся или F5 во время обработки, сессия восстанавливается автоматически. Если загрузить тот же файл в течение часа — предлагается продолжить с прерванного этапа.
- **Тост-уведомления** — быстрые сообщения о старте задачи, завершении, ошибках.
- **Скорость загрузки** — показывается в реальном времени (MB/s) во время отправки файла.
- Закрытие модального окна по Escape.

## Запуск

```bash
pip install fastapi uvicorn[standard] python-multipart
uvicorn main:app --port 8000 --reload
```

## Стек
- Backend: Python 3.11+ / FastAPI / Uvicorn
- Frontend: Vanilla JS / Canvas API / CSS animations
- Нет зависимостей от React, Vue и npm

## Ограничения
- ModForge не запускает BeamNG.drive для живого 3D-рендера
- Неизвестная Lua-логика и физика не гарантируют исправление
- Закрытые игровые ассеты не копируются
