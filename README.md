# ModForge v1 (0.26)

Глобальный релиз ветки v1 для BeamNG.drive 0.39.

## Что изменилось
- Полностью переработанный строгий адаптивный интерфейс.
- Анимированное состояние запуска вместо неясной неактивной кнопки.
- Preflight-проверка backend перед большой загрузкой.
- Ясные ошибки MF-404, MF-503, MF-TIMEOUT, MF-413, MF-415, MF-422, MF-409.
- ZIP, папка и отдельные поддерживаемые BeamNG-файлы.
- 11 этапов анализа, ремонт, пост-проверка, полный re-check и финальная проверка.
- Changelog показывается при первом входе после выпуска новой версии.
- Политика конфиденциальности и инструкция — только один раз на браузер.
- Настройка суффикса результата.
- Слабый анимированный фон без влияния на управление.

## Поддерживаемые одиночные файлы
JBeam, PC, JSON/JSONC, Lua, materials, prefab, DAE/CDAE, DDS, PNG/JPG/JPEG/TGA/BMP/GIF, CS, CFG, MIS, FOREST, TER и связанные JSON-форматы.

Отдельные изображения и бинарные ресурсы проверяются в пределах доступных статических признаков; пиксельное содержимое автоматически не редактируется.

## Ограничения
ModForge не запускает BeamNG.drive для живого 3D-рендера и не обещает исправить ошибки, для которых нужен реальный запуск игры. Закрытые игровые ассеты BeamNG не скачиваются и не копируются.

## Deploy
Загрузи содержимое этой папки в корень GitHub-репозитория. Render может собирать Dockerfile автоматически.
