# ModForge v1 (0.28) — BeamNG.drive mod repair

## Что изменено в 0.28

### Интерфейс
- Убран `ONLINE` и `LIVE`; верхняя панель стала строже и чище.
- Добавлен заметный, но малоконтрастный анимированный фон и фирменный banner.
- Загруженный логотип используется как favicon, логотип в шапке и визуальный знак проекта.
- Кнопки `ZIP / Папка / Файл` после выбора превращаются в компактную иконку выбранного типа с анимацией появления.
- Анимации переведены на короткие плавные переходы с уважением к `prefers-reduced-motion`.
- Клик по логотипу больше не перезагружает страницу и не сбрасывает рабочую форму.
- Черновик настроек (пожелания, приоритет, формат, суффикс) сохраняется в браузере.

### Надёжность скачивания
- Кнопка скачивания теперь сначала проверяет доступность готового результата через `HEAD`.
- При проблеме с готовым файлом появляется отдельный анимированный блок ошибки с кодом `MF-404` или другим фактическим кодом.
- В ошибке есть `Перезапустить всё`: текущий выбранный файл и настройки используются повторно без повторного выбора.
- Готовые задания сохраняются на диске вместе с метаданными и могут быть восстановлены после перезапуска backend-процесса, пока рабочая директория доступна.
- Срок хранения результатов по умолчанию увеличен до 24 часов; можно изменить через `MODFORGE_JOB_RETENTION`.
- Для постоянного хранения в облачном окружении можно указать `MODFORGE_WORK_ROOT` на подключённый persistent volume.

### Обратная связь
- Добавлен раздел `Обратная связь`.
- Пользователи могут создавать сообщения, отвечать друг другу и отправлять жалобу на сообщение.
- Сообщения хранятся в `MODFORGE_FEEDBACK_PATH` (по умолчанию рядом с рабочим хранилищем ModForge).

### Backend
- Добавлен `HEAD /api/jobs/{job_id}/download` для безопасной проверки выдачи.
- Завершённые задания восстанавливаются из `job.json` после перезапуска процесса.
- Отчёт содержит прямые URL результата и JSON-отчёта.

## Запуск

```bash
pip install fastapi uvicorn[standard] python-multipart
uvicorn main:app --port 8000 --reload
```

## Стек
- Backend: Python 3.11+ / FastAPI / Uvicorn
- Frontend: Vanilla JS / Canvas API / CSS animations
- Нет зависимостей от React, Vue и npm

## Ограничения
- ModForge не запускает BeamNG.drive для живого 3D-рендера.
- Неизвестная Lua-логика и физика не гарантируют исправление.
- Закрытые игровые ассеты не копируются.
