# ModForge v1 (0.29) — BeamNG.drive mod repair

## Что изменено в 0.29

### Интерфейс
- Убран `ONLINE` и `LIVE`; верхняя панель стала строже и чище.
- Добавлен заметный, но малоконтрастный анимированный фон и фирменный banner.
- Загруженный логотип используется как favicon, логотип в шапке и визуальный знак проекта.
- Кнопки `ZIP / Папка / Файл` после выбора превращаются в компактную иконку выбранного типа с анимацией появления.
- Анимации переведены на короткие плавные переходы с уважением к `prefers-reduced-motion`.
- Клик по логотипу больше не перезагружает страницу и не сбрасывает рабочую форму.
- Черновик настроек (пожелания, приоритет, формат, суффикс) сохраняется в браузере.

### Надёжность скачивания
- Кнопка скачивания теперь сначала проверяет доступность готового результата через `HEAD`.
- При проблеме с готовым файлом появляется отдельный анимированный блок ошибки с кодом `MF-404` или другим фактическим кодом.
- В ошибке есть `Перезапустить всё`: текущий выбранный файл и настройки используются повторно без повторного выбора.
- Готовые задания сохраняются на диске вместе с метаданными и могут быть восстановлены после перезапуска backend-процесса, пока рабочая директория доступна.
- Срок хранения результатов по умолчанию увеличен до 7 дней; можно изменить через `MODFORGE_JOB_RETENTION`.
- Готовый архив можно автоматически пересобрать из сохранённой рабочей копии, если исходный output-файл исчез после перезапуска.
- Активная задача и последний результат восстанавливаются после закрытия браузера через локальный reference; повторная загрузка исходника для перезапуска не нужна, пока серверное хранилище доступно.
- Для постоянного хранения в облачном окружении можно указать `MODFORGE_DATA_ROOT`/`MODFORGE_WORK_ROOT` на подключённый persistent volume. По умолчанию используется `./data/jobs`, а не `/tmp`. В Docker примонтируйте `/app/data` как persistent volume.

### Обратная связь
- Добавлен раздел `Обратная связь`.
- Пользователи могут создавать сообщения, отвечать друг другу и отправлять жалобу на сообщение.
- Сообщения и жалобы хранятся в `MODFORGE_FEEDBACK_PATH` (до 5000 последних записей, с логом жалоб).
- Новые сообщения и жалобы отправляются на `ptornsaso0h@gmail.com` только при настроенном SMTP.
- Пользователь может оставить email для ответа; email не публикуется в открытом списке.
- Автор ModForge входит через `MODFORGE_ADMIN_KEY`; авторский ответ помечается как ответ автора и отправляется на email пользователя, если он был указан.

### Backend
- Добавлен `HEAD /api/jobs/{job_id}/download` для безопасной проверки выдачи.
- Скачивание запускается через скрытую ссылку без ухода со страницы, чтобы не сбрасывать интерфейс.
- JSON-отчёт скачивается без навигации и тоже не сбрасывает страницу.
- Завершённые задания восстанавливаются из `job.json` после перезапуска процесса.
- Отчёт содержит прямые URL результата и JSON-отчёта.

## Email и режим автора

Для уведомлений задайте переменные окружения:

```text
MODFORGE_SMTP_HOST=smtp.example.com
MODFORGE_SMTP_PORT=587
MODFORGE_SMTP_USER=...
MODFORGE_SMTP_PASSWORD=...
MODFORGE_SMTP_FROM=...   # необязательно
MODFORGE_SMTP_TLS=1
MODFORGE_ADMIN_KEY=длинный_секретный_ключ
```

Получатель уведомлений владельца фиксирован как `ptornsaso0h@gmail.com`. Сам архив и данные жалоб сначала сохраняются на диске; SMTP — только канал уведомлений.

## Запуск

```bash
pip install fastapi uvicorn[standard] python-multipart
uvicorn main:app --port 8000 --reload
```

## Стек
- Backend: Python 3.11+ / FastAPI / Uvicorn
- Frontend: Vanilla JS / Canvas API / CSS animations
- Нет зависимостей от React, Vue и npm

## Ограничения
- ModForge не запускает BeamNG.drive для живого 3D-рендера.
- Неизвестная Lua-логика и физика не гарантируют исправление.
- Закрытые игровые ассеты не копируются.
